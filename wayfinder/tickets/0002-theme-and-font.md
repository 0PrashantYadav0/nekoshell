## Question

Which theme family do we commit to across iTerm2, prompt, bat, eza, fzf, delta, btop and lazygit, and which Nerd Font? Recommendation: Catppuccin Mocha (widest set of official ports) and JetBrainsMono Nerd Font via `brew install --cask font-jetbrains-mono-nerd-font`. Alternatives: Tokyo Night, Rosé Pine, Gruvbox; keep MesloLGS NF.

## Resolution

Decided by the user on 2026-09-11: **Catppuccin Mocha** everywhere, **JetBrainsMono Nerd Font** at 15 pt with ligatures on (`brew install --cask font-jetbrains-mono-nerd-font`). MesloLGS NF stays installed as the fallback font.
