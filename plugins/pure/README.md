# pure

## What it does

Puts [pure](https://github.com/sindresorhus/pure) in place of Starship: a
one-line prompt with the path, the git branch and its state, the last
command's duration when it took a while, and a `❯` that turns red after a
failure. Its colours come from the flavour and follow every `nekoshell
theme` switch. The core zshrc sees `NEKOSHELL_PROMPT=pure` and does not start
Starship.

It conflicts with the p10k plugin: one prompt at a time.

## Installs

`pure` (Homebrew formula), which puts `prompt_pure_setup` and `async` under
Homebrew's `share/zsh/site-functions`.

## Files

Generated by nekoshell and rewritten on every theme switch:

- `~/.config/nekoshell/pure-colors.zsh` — the zstyles that colour the
  prompt, from `files/pure-colors.zsh.tmpl` beside this README.

Nothing of yours.

## After install

Open a new terminal. To change a colour, edit the template and run
`nekoshell theme <flavour>`.

## Remove

`nekoshell plugin remove pure` hands the prompt back to Starship in the next
shell; `--purge` uninstalls pure too.
