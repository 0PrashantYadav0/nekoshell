# yazi

## What it does

Installs [yazi](https://yazi-rs.github.io), a terminal file manager with
previews, and dresses it in the flavour: `theme.toml` is rendered from the
Catppuccin flavour on every `nekoshell theme` switch. A `y` function opens
yazi and, when you quit, leaves the shell in the directory you were looking
at. Previews of files use the tools other plugins bring (bat, fd, ripgrep,
zoxide from modern-cli and fzf).

## Installs

`yazi` (Homebrew formula). Image, video and PDF previews want `ffmpeg`,
`poppler`, `resvg` and `imagemagick`, which are yours to add.

## Files

Copied into your home, once, and yours from then on:

- `~/.config/yazi/yazi.toml` — a short settings file; one already there is
  left alone

Generated by nekoshell and rewritten on every theme switch:

- `~/.config/yazi/theme.toml` — from `files/theme.toml.tmpl` beside this
  README, derived from yazi's own Catppuccin flavour. A theme of your own at
  that path is backed up before the first render.

## After install

Nothing. `y` in a new shell, `q` to quit where you are.

## Remove

`nekoshell plugin remove yazi` takes the function and the rendered
`theme.toml` away; your `yazi.toml` stays. Add `--purge` to uninstall yazi
too.
