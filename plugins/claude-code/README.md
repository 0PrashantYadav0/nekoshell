# claude-code

## What it does

Dresses [Claude Code](https://code.claude.com) in the flavour and puts the
[ai](../ai/README.md) plugin's welcome banner in front of every interactive
session:

- A custom theme, `~/.claude/themes/nekoshell.json`, with the Catppuccin
  colours for the brand accent, text, borders, plan and accept modes, the
  message backgrounds and the rest; `theme = "custom:nekoshell"` is set in
  `~/.claude/settings.json`. Rendered again on every `nekoshell theme`
  switch, with a light base for latte and a dark one otherwise; Claude Code
  reloads the file on its own.
- A status line, `~/.config/nekoshell/ai/claude-statusline.sh`, showing the
  model, the directory, the git branch and the context use in the flavour's
  colours; `statusLine` in `settings.json` points at it.
- A `claude` shell function that prints the banner and then runs the real
  binary. `claude -p`, `--version`, `--help` and the subcommands (`mcp`,
  `config`, `plugin`, `update`, `doctor`, `install`, `auth`) run untouched,
  as does any use where stdout is not a terminal.

The previous `theme` and `statusLine` values are recorded in
`~/.config/nekoshell/ai/claude-previous.json` and put back on removal.

## Installs

Nothing from Homebrew: Claude Code is usually installed by its own installer
or through npm, and a second copy from a cask would only get in the way. The
install hook says `brew install --cask claude-code` when the binary is
missing.

## Files

Generated by nekoshell and rewritten on every theme switch:

- `~/.claude/themes/nekoshell.json` — from `files/theme.json.tmpl`
- `~/.config/nekoshell/ai/claude-statusline.sh` — from
  `files/statusline.sh.tmpl`

Touched in place, two keys only: `theme` and `statusLine` in
`~/.claude/settings.json`. The rest of that file is yours.

## After install

Start `claude` from a terminal. If `~/.claude/themes/` did not exist before,
restart Claude Code once; after that a theme switch applies live. `/theme`
shows "nekoshell Mocha" selected.

## Remove

`nekoshell plugin remove claude-code` restores the two settings, removes the
rendered theme and status line, and drops the shell function. Claude Code
stays.
