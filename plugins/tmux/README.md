# tmux

## What it does

Sets up [tmux](https://github.com/tmux/tmux) so a terminal window can hold
several panes and outlive the window itself: `t` attaches to a session called
`main`, creating it the first time.

The prefix is `C-a` (`C-b` still works), panes split with `|` and `-` and are
walked with `h j k l`, the mouse works, and the status line is Catppuccin in
whatever flavour the rest of nekoshell is wearing.

The flavour lives in a generated file the config sources, not in the config
itself, so `nekoshell theme latte` never touches the file you edit.

## Installs

`tmux` (Homebrew formula), and [TPM](https://github.com/tmux-plugins/tpm), the
tmux plugin manager, cloned at a pinned commit into
`~/.config/tmux/plugins/tpm`. TPM then fetches tmux-sensible, tmux-yank and
catppuccin/tmux when you ask it to.

## Files

Copied into your home, once, and yours from then on:

- `~/.config/tmux/tmux.conf`

Generated by nekoshell and rewritten on every theme switch:

- `~/.config/tmux/nekoshell-theme.conf` — the Catppuccin flavour

The shipped config sources every `~/.config/tmux/nekoshell-*.conf`, so other
plugins can drop their own generated tmux settings there without either of us
editing your config.

If `~/.tmux.conf` or `~/.config/tmux/tmux.conf` already exists, nothing is
copied and the add says so. The file is still readable in the checkout under
`plugins/tmux/files/copy` if you want to take pieces of it by hand.

## After install

Start tmux and press `C-a I` once (capital I) to let TPM fetch the plugins.
It takes a few seconds and only happens the first time.

## Remove

`nekoshell plugin remove tmux` drops the `t` alias. Your `tmux.conf` stays
where it is — it is yours — as does the TPM clone. Add `--purge` to uninstall
the formula too, as long as no other enabled plugin needs it.
