# opencode

## What it does

Installs [OpenCode](https://opencode.ai), the open-source AI coding agent
for the terminal, dresses it in the flavour and puts the
[ai](../ai/README.md) plugin's welcome banner in front of every interactive
session:

- A theme, `~/.config/opencode/themes/nekoshell.json`, with every one of
  OpenCode's fifty colour keys mapped to a Catppuccin palette role (the same
  mapping as OpenCode's built-in catppuccin theme, with the two diff
  background tints on the surface colours), and `"theme": "nekoshell"` in
  `~/.config/opencode/tui.json`. Rendered again on every `nekoshell theme`
  switch.
- An `opencode` shell function that prints the banner and then runs the
  real binary. `opencode run`, `serve`, `auth`, `upgrade`, `models`,
  `--version` and `--help` run untouched, as does any use where stdout is
  not a terminal.

The previous `theme` value is recorded in
`~/.config/nekoshell/ai/opencode-previous.json` and put back on removal.

## Installs

`opencode` (Homebrew formula).

## Files

Generated by nekoshell and rewritten on every theme switch:

- `~/.config/opencode/themes/nekoshell.json` — from `files/theme.json.tmpl`

Touched in place, one key only: `theme` in `~/.config/opencode/tui.json`
(created when missing). The rest of your OpenCode configuration is yours.

## After install

Start `opencode` from a terminal; the theme is on. Restart a running
OpenCode after a flavour switch.

## Remove

`nekoshell plugin remove opencode` restores the `theme` key, removes the
rendered theme and drops the shell function; `--purge` uninstalls OpenCode
too.
