# ai

## What it does

The base the AI tool plugins (claude-code, opencode) stand on: a welcome
banner printed just before the tool starts, naming the tool, the project and
branch you are in, and the last commit:

```text
Welcome to Claude Code. You are in nekoshell on main.
Last commit 5832ced "Merge pull request #5" 2 hours ago.
```

Outside a repository it says the directory and that it is not one. The text
is yours: `~/.config/nekoshell/ai/welcome.txt` (and `welcome-norepo.txt`)
with the placeholders `@@TOOL@@ @@PROJECT@@ @@BRANCH@@ @@COMMIT@@ @@SUBJECT@@
@@WHEN@@ @@DIR@@`; a `welcome.claude-code.txt` beside them wins for that
tool. The values are drawn in the flavour's accent colour.

`nekoshell ai welcome [TOOL]` previews it, `nekoshell ai edit` opens the
template, `nekoshell ai status` lists the tool plugins. The banner is silent
when stdout is not a terminal, and `NEKOSHELL_AI_WELCOME=0` switches it off.

## Installs

Nothing from Homebrew. The tool plugins bring their tools.

## Files

Copied into your home, once, and yours from then on:

- `~/.config/nekoshell/ai/welcome.txt` and `welcome-norepo.txt`

Generated by nekoshell and rewritten on every theme switch:

- `~/.config/nekoshell/ai/colors.sh` — the banner's colours, from
  `files/colors.sh.tmpl` beside this README

## After install

Add a tool plugin: `nekoshell plugin add claude-code` or `opencode`.

## Remove

`nekoshell plugin remove ai` (after the tool plugins, which need it) takes
`nekoshell ai` and the banner program away; your templates stay.
