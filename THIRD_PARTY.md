in this tree. The commits and tags below are the ones the shipped configs were written and
checked against.

The Neovim plugin versions live in that `plugins.lua` rather than in a lockfile of this repo,
because the file becomes the user's own the moment it is copied into `~/.config/nvim/`, and
lazy.nvim records the exact commits it resolved in a `lazy-lock.json` beside it. That lockfile
is the user's; it is not shipped.
