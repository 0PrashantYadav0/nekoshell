# p10k

## What you get

Powerlevel10k as the prompt in place of Starship, with the lean two-line config that ships here: the directory and git status on the first line, the prompt character on the second (`❯`, or `❮` in vi command mode, red after a failed command), and on the right the last command's duration when it took 5 seconds or more, the Python virtualenv, user@host and a 12-hour clock with seconds. No backgrounds, no segment icons, no transient prompt. Starship stays installed and returns the moment the plugin is removed.

Powerlevel10k's instant prompt is on unless the greet plugin is also enabled: the two would fight for the top of the window, so with greet it is off and the prompt arrives after the greeting.

## Using it

Nothing to type. `p10k configure` runs Powerlevel10k's own wizard and rewrites `~/.p10k.zsh`; a file it writes no longer reads the nekoshell colours below.

## Files

| Path | How | Edit it? |
| --- | --- | --- |
| `~/.p10k.zsh` | copied once; an existing one is kept and the add says so | yes; delete it and add the plugin again to get the shipped one |
| `~/.config/nekoshell/p10k-colors.zsh` | rendered on add and on every theme switch | no |

Load order: the plugin's `early.zsh` sources the instant-prompt cache before anything else; `plugin.zsh` sets `NEKOSHELL_PROMPT=p10k` so the zshrc skips Starship, sources Homebrew's `powerlevel10k.zsh-theme`, then `p10k-colors.zsh`, then your `~/.p10k.zsh`, so your file wins.

## Theme

`p10k-colors.zsh` exports seven variables from the flavour's palette, and the shipped `~/.p10k.zsh` reads them, with fallbacks for a shell where the file is missing:

| Variable | Palette colour | Used for |
| --- | --- | --- |
| `NEKOSHELL_P10K_GREY` | overlay1 | git status, user@host, virtualenv, clock |
| `NEKOSHELL_P10K_RED` | red | the prompt character after a failed command |
| `NEKOSHELL_P10K_YELLOW` | yellow | command duration |
| `NEKOSHELL_P10K_BLUE` | blue | directory |
| `NEKOSHELL_P10K_MAGENTA` | pink | the prompt character |
| `NEKOSHELL_P10K_CYAN` | teal | commits ahead and behind |
| `NEKOSHELL_P10K_WHITE` | text | the user name when root |

`nekoshell theme <flavour>` rewrites the colours file; a new shell shows them. Doctor rows: `p10k theme` (the Homebrew file), `p10k config` (warns without a `~/.p10k.zsh`), `p10k colours` (fails when the file is not rendered for the flavour in force).

The shipped config sets `POWERLEVEL9K_INSTANT_PROMPT=${NEKOSHELL_P10K_INSTANT_PROMPT:-verbose}`, and `early.zsh` sets that variable to `off` when greet is enabled. If you keep a `~/.p10k.zsh` of your own and use greet, set `POWERLEVEL9K_INSTANT_PROMPT=off` (or `quiet`) in it to silence the instant prompt warning.

## Turning it off

The [pure](pure.md) plugin is the other prompt; the two refuse to be enabled together.

`nekoshell plugin remove p10k`; Starship takes the prompt back on the next shell. `~/.p10k.zsh` and the rendered colours file stay. `--purge` also uninstalls the powerlevel10k formula.
