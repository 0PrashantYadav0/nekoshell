# nekoshell v0.1 spec

Consolidated from the Wayfinder map (`wayfinder/MAP.md`, tickets 0001 to 0013) and the decisions the user locked on 2026-09-11. This is the binding authority for the v0.1 build plan. Vocabulary is defined in `CONTEXT.md`.

## What v0.1 is

A public, MIT-licensed repo (`0PrashantYadav0/nekoshell`) that turns a fresh macOS machine with iTerm2 into the **rig**:

1. **Look.** One theme (Catppuccin Mocha) applied to iTerm2, the prompt, and the everyday CLI tools. Font JetBrainsMono Nerd Font 15 pt with ligatures.
2. **Greeting.** A new interactive terminal prints a piece of art (Pokémon colourscript 70 percent of the time, an image from the user's art pack 30 percent) beside live machine stats. Under 150 ms.
3. **Panel.** A global hotkey (⌥M) shows and hides an iTerm2 dedicated hotkey window docked to the right edge of the screen running spotify_player. Premium is the primary path; a free-tier remote exists as fallback.
4. **Installer.** `install.sh` is idempotent, backs up whatever it replaces, and has `--check` and `--dry-run`. `nekoshell-doctor` proves the rig works. `uninstall.sh` restores backups.
5. **Docs for humans and agents.** README, INSTALL.md, REMOTE.md, AGENTS.md, CONTRIBUTING.md, CHANGELOG.md, and a shipped skill folder so `npx skills add 0PrashantYadav0/nekoshell` teaches any agent the workflow.

## Platform and constraints

- macOS only (tested on macOS 26.5, Apple Silicon). iTerm2 3.5 or newer. zsh 5.9. Homebrew is the only package source.
- Lightweight: no daemons at login, no Electron, no Python at shell startup. Python 3 (system or Homebrew) may be used by the installer and by build scripts.
- The repo never bundles copyrighted images. Pokémon sprites stay upstream in pokemon-colorscripts (a dependency cloned at install time). The art pack ships only original or CC0 samples with attribution.
- Every shell script passes shellcheck. Every behaviour with a branch has a bats test. CI runs shellcheck and bats on `macos-latest`.
- Config root on the user's machine is `~/.config/nekoshell/`. Cache is `~/.cache/nekoshell/`. The repo checkout can live anywhere; scripts locate it through the stowed `~/.zshrc` symlink or `~/.config/nekoshell/root`.
- Nothing in the rig runs when `CLAUDECODE` is set, inside tmux, inside the panel, or over SSH (unless `NEKOSHELL_GREET_SSH=1`).

## iTerm2 profiles

Two profiles in one dynamic profile file `~/Library/Application Support/iTerm2/DynamicProfiles/nekoshell.json`, generated by `iterm2/build-profiles.py` at install time with the absolute repo path baked in.

- **nekoshell** (main): Guid `4E4B4F53-4845-4C4C-0001-000000000001`. Font `JetBrainsMonoNF-Regular 15`, ligatures on, non-ASCII font off. Transparency 0.10, blur on, blur radius 24. Cursor vertical bar, blinking off. Unlimited scrollback. Silence bell. Status bar off. Window type Normal (0).
- **nekoshell panel**: Guid `4E4B4F53-4845-4C4C-0002-000000000002`. Same colours and font. `Has Hotkey` true, key code 46, characters `µ`, characters ignoring modifiers `m`, modifier flags 524288, animates true, auto-hides true, floats true, reopens on activation false, Space -1 (all spaces), Columns 60, Rows 40. `Window Type` set to the numeric value for "Right of screen" (believed 6; must be verified on the machine and corrected if wrong). Command: `/usr/bin/env NEKOSHELL_PANEL=1 <root>/bin/nekoshell-music`, Custom Command `Yes`. Transparency 0.06.

Global iTerm2 preferences applied with `defaults write com.googlecode.iterm2` only when iTerm2 is not running (iTerm2 overwrites the plist on quit): `Default Bookmark Guid` = main Guid, `HideTab` true, `TerminalMargin` 16, `TerminalVMargin` 12, `PromptOnQuit` false, `HideScrollbar` true.

## Shell stack

- `~/.zshrc` is a stow symlink into the repo. It sets `NEKOSHELL_ROOT` from its own real path, prepends `$NEKOSHELL_ROOT/bin` and `~/.local/bin` to PATH, loads antidote plugins from `~/.config/nekoshell/zsh/plugins.txt` (zsh-users/zsh-autosuggestions, zsh-users/zsh-syntax-highlighting, zsh-users/zsh-completions, Aloxaf/fzf-tab), sources `~/.config/nekoshell/zsh/env.zsh` and `aliases.zsh` and, if present, `~/.config/nekoshell/zsh/local.zsh` (user overrides, never stowed), inits zoxide and fzf, inits Starship, and finally runs `nekoshell-greet` when the shell is interactive.
- The user's existing aliases from the pre-install `~/.zshrc` are copied into `~/.config/nekoshell/zsh/local.zsh` by the installer (lines beginning with `alias ` or `export ` that are not oh-my-zsh or p10k related).
- Starship config `~/.config/starship.toml` with the Mocha palette: directory blue, git branch mauve, git status red, cmd_duration yellow, success character `❯` pink, error character red. Right prompt shows cmd_duration only.
- Tools installed by the Brewfile: starship, antidote, fastfetch, fzf, eza, bat, zoxide, ripgrep, fd, git-delta, btop, lazygit, spotify_player, shpotify, stow, bats-core, shellcheck, and casks font-jetbrains-mono-nerd-font, iterm2 (cask is a no-op when already installed).
- Themed configs: bat (`--theme` Catppuccin Mocha via the bat theme file vendored from catppuccin/bat, MIT), eza colours through `EZA_COLORS`, fzf colours through `FZF_DEFAULT_OPTS`, delta through a gitconfig include the installer adds to `~/.gitconfig` once, btop theme file vendored from catppuccin/btop (MIT), lazygit theme in its config.yml.

## Greeting

`bin/nekoshell-greet` (bash):

1. Exit silently unless stdout is a TTY. Exit when any of `NEKOSHELL_NO_GREET`, `CLAUDECODE`, `TMUX`, `NEKOSHELL_PANEL` is set, or when `SSH_CONNECTION` is set without `NEKOSHELL_GREET_SSH`.
2. Read `~/.config/nekoshell/greet.conf` (shell variables): `POKEMON_SHARE=70`, `SHINY_ODDS=128`, `GENERATIONS=""`, `IMAGE_WIDTH=28`, `IMAGE_HEIGHT=14`. Missing file means defaults.
3. Roll with bash `RANDOM`; `NEKOSHELL_SEED` seeds `RANDOM` for tests. Pokémon when roll < POKEMON_SHARE, or when the art pack `~/.config/nekoshell/art/` has no PNG/JPG, or when `TERM_PROGRAM` is not `iTerm.app`. Otherwise a random image from the art pack.
4. Pokémon: run `pokemon-colorscripts -r [GENERATIONS] [-s]` once (shiny when a second roll hits 1 in SHINY_ODDS). First line is the name; the rest is the sprite. Write `<name>` (plus ` ✦ shiny`) to `~/.cache/nekoshell/art-name`, pipe the sprite into `fastfetch --config ~/.config/fastfetch/config.jsonc --file-raw -`.
5. Image: write the file's basename to `~/.cache/nekoshell/art-name`, run `fastfetch --config ... --iterm <path> --logo-width IMAGE_WIDTH --logo-height IMAGE_HEIGHT`.
6. If pokemon-colorscripts or fastfetch is missing, print nothing and exit 0. Never print an error into a fresh shell.
7. `NEKOSHELL_GREET_TIME=1` prints the elapsed milliseconds on the last line.

`~/.config/fastfetch/config.jsonc` shows, in order: title (user@host), separator, OS, Host, Kernel, Uptime, Shell, Terminal, Terminal Font, CPU, Memory, Packages, an `Art` line from the `command` module reading `~/.cache/nekoshell/art-name`, a blank line, and the colour blocks. Keys in mauve, title in blue, separator two spaces.

`bin/nekoshell-art` manages the art pack: `add <file>` copies an image in, `list` prints it, `sample` regenerates the shipped samples. The repo ships `art/` with three original pixel-art PNGs generated by `scripts/gen-sample-art.py` (pure Python, no Pillow) and an `art/README.md` on licensing and adding your own.

## Panel

`bin/nekoshell-music` (bash): sets `NEKOSHELL_PANEL=1`. If `spotify_player` exists and `~/.cache/spotify-player/` contains cached credentials, exec `spotify_player`. If it exists but has no credentials, print a two-line notice and run `spotify_player authenticate` then exec `spotify_player`. If `spotify_player` is missing or `--remote` is passed, run the shpotify remote: a single-key loop (space play/pause, n next, p previous, + and - volume, s status, q quit) driving the `spotify` command from shpotify.

`~/.config/spotify-player/app.toml`: `theme = "catppuccin_mocha"`, `enable_media_control = false`, `playback_window_position = "Top"`, `[device] name = "nekoshell"`, `volume = 70`, `bitrate = 320`. `theme.toml` defines `catppuccin_mocha` with the palette above.

## Installer, doctor, uninstaller

`install.sh` runs from any checkout path. Flags: `--check` (report what would change, exit 0 if nothing), `--dry-run` (print every command, run none), `--yes` (no prompts), `--skip-brew`, `--skip-spotify`, `--iterm-prefs` (only apply the global iTerm2 prefs step). Steps in order, each printed with a status:

1. Preflight: macOS, Homebrew present (offer the install command, do not run it), iTerm2 app present, zsh.
2. `brew bundle --file Brewfile` (skipped with `--skip-brew`).
3. Backup: every file stow would replace (`~/.zshrc`, `~/.config/starship.toml`, `~/.config/fastfetch/`, `~/.config/spotify-player/`, `~/.config/bat/`, `~/.config/btop/`, `~/.config/lazygit/`) is moved to `~/.local/share/nekoshell/backup/<UTC timestamp>/` preserving relative paths. A manifest lists them.
4. Migrate aliases from the backed-up `.zshrc` into `~/.config/nekoshell/zsh/local.zsh` if that file does not exist yet.
5. `stow -d <root>/stow -t ~ zsh config`.
6. Write `~/.config/nekoshell/root` with the absolute checkout path.
7. Clone pokemon-colorscripts into `~/.local/share/pokemon-colorscripts` at the pinned commit in `deps.lock`, symlink `~/.local/bin/pokemon-colorscripts`.
8. Add the delta include to `~/.gitconfig` once (guarded by a marker comment).
9. Generate the iTerm2 dynamic profile file from `iterm2/build-profiles.py`.
10. Apply global iTerm2 prefs if iTerm2 is not running; otherwise print the exact command to run later and mark the step as pending.
11. Print the human steps: restart iTerm2, run `spotify_player authenticate`, press ⌥M.

`bin/nekoshell-doctor` prints one line per check with `ok`, `warn`, or `fail` and exits non-zero if any check fails: Homebrew, each Brewfile tool on PATH, the Nerd Font file in `~/Library/Fonts` or `/Library/Fonts`, `~/.zshrc` is a symlink into the repo, `~/.config/nekoshell/root` matches, dynamic profile file present and both Guids inside, iTerm2 default profile Guid is the main one (warn if not), pokemon-colorscripts runs, fastfetch runs, greet time under 150 ms (`NEKOSHELL_SEED=1 NEKOSHELL_GREET_TIME=1`), spotify_player credentials present (warn if not), pending iTerm2 prefs (warn). `--json` prints the same as a JSON array for agents.

`uninstall.sh` unstows, restores the newest backup manifest, removes the dynamic profile file and `~/.config/nekoshell/root`, and leaves Homebrew packages alone (prints the `brew` command to remove them).

## Docs

- `README.md`: what it is, one screenshot of the greeting and one of the panel (captured in the final on-machine task into `docs/screenshots/`), 3-command install, the human steps, the hotkey, how to add art, how to change the theme, links to the other docs.
- `docs/INSTALL.md`: full step-by-step for humans including the "run from Terminal.app so iTerm2 can be quit" note.
- `docs/REMOTE.md`: what carries to SSH hosts, Codespaces and devcontainers (shell, prompt, tools, greeting opt-in) and what does not (panel, fonts), with the `--skip-spotify` invocation and the `NEKOSHELL_GREET_SSH=1` opt-in.
- `AGENTS.md`: the contract for agents: preconditions with the command for each, the single install command for unattended mode (`./install.sh --yes`), the doctor command and the exact success condition (exit 0, or exit 0 with only `warn` lines about Spotify credentials and pending iTerm2 prefs), the human steps the agent must hand over (Spotify OAuth in a browser; quitting iTerm2 for global prefs), what the installer backs up and where, and a rule: never pass `--force`-like behaviour, never delete the backup directory.
- `skills/nekoshell/SKILL.md`: a skill (frontmatter `name`, `description`) that tells an agent to clone the repo, run the installer unattended, run the doctor, and relay the human steps.
- `CONTRIBUTING.md`, `CHANGELOG.md` (v0.1.0 entry), `LICENSE` (MIT, Prashant Kumar Yadav, 2026).

## Out of scope for v0.1

Linux terminals, Windows, shells other than zsh, tmux as a first-class feature (a `--remote` tmux fallback for the panel is not built), runtime light/dark switching, replacing iTerm2.
